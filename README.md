# 📅 Завдання 1–7: Робота з датою та часом у Python

## 📌 Опис

Цей проєкт містить виконання **завдань 1–7** з теми **«Робота з датою та часом у Python»**.

Для виконання завдань використовується стандартний модуль **`datetime`**.

## 📝 Завдання

### 🔹 Завдання 1

Створення програми, яка виводить **поточну дату та час**.

### 🔹 Завдання 2

Створення програми, яка запитує дату у форматі `дд.мм.рррр` та **перевіряє її коректність**.

### 🔹 Завдання 3

Створення функції, яка приймає **дату народження користувача** та повертає його вік.

### 🔹 Завдання 4

Створення програми, яка **обчислює різницю в часі між двома датами**, введеними користувачем.

### 🔹 Завдання 5

Створення функції, яка визначає **привітання залежно від часу доби**:

* 🌅 Доброго ранку
* ☀️ Доброго дня
* 🌆 Доброго вечора
* 🌙 Доброї ночі

### 🔹 Завдання 6

Створення функції, яка **перетворює рядок з датою** у форматі `дд.мм.рррр` на об'єкт `datetime`.

### 🔹 Завдання 7

Створення програми, яка **визначає кількість днів, що залишилася до заданої дати**.
